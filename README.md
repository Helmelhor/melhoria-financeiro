## **📌 Visão Geral**  
Aplicação completa para gestão financeira pessoal com:  
✔ **Análise visual** de gastos e receitas  
✔ **Planejamento** de metas financeiras  
✔ **Assistente AI** especializado em finanças (Valer.ia)  

---

## **✨ Funcionalidades**  

### **1. 📤 Importação de Dados**  
- Upload de arquivos CSV no formato pré-definido  
- Validação automática da estrutura dos dados  

### **2. 📊 Dashboard Financeiro**  
- Gráfico de pizza com distribuição de gastos  
- Métricas-chave:  
  - Movimentações bancárias  
  - Soma renda fixa  
  - Soma gastos no pix  

### **3. 🎯 Metas Financeiras**  
- Simulador de economia com projeção temporal  
- Cálculo automático de:  
  - Valor necessário/mês  
  - Tempo para alcançar objetivo  

### **4. 💬 Valer.ia - Assistente Financeiro**  
- Chatbot com Gemini AI para:  
  - Análise dos seus dados  
  - Dicas de economia  
  - Explicações sobre métricas
